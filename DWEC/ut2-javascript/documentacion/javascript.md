# Estructuras 

## Arrays
Permite almacenar una colección de datos a
los que permite acceder de forma aleatoria

### Métodos

| Método | Descripción |
|-----------|-----------|
| length          | Conocer la longitud del array           |      
| push()    | Añadir un elemento al final    |
| splice()    | Añadir o eliminar elementos    |
| at()    | Obtener el valor almacenado en una posición    |
| sort()    | Ordenar el array    |
| find()    | Buscar el elemento que pasa la prueba   |
| includes()   | Comprobar si contiene un elemento   |
