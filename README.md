## 📌 Descripción del Proyecto
Aplicación web interactiva desarrollada en **JavaScript Vanilla (ES6+)** enfocada en la manipulación dinámica del DOM y la comunicación asíncrona con servicios web. El proyecto implementa renderizado dinámico de componentes en el navegador, validación de formularios en tiempo real y persistencia del estado en el cliente utilizando `LocalStorage`.
